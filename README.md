# 세워도 돼?

앱을 열면 지금 이 자리에 주정차해도 되는지, 몇 시까지인지, 무엇을 근거로 그렇게 판정했는지 알려 주는 웹앱입니다. 2026 엘리스 AI 챌린지 출품용 PoC입니다.

## 쓰는 데이터

- 전국주정차금지(지정)구역표준데이터 (공공데이터포털 15034542, 기준일 2026-10-12). 시연판은 서울 금천구 125개 구간 중 69개를 좌표로 바꿔 씁니다. 나머지 56개는 구간 끝 주소를 지도에서 찾지 못해 뺐습니다.
- 전국어린이보호구역표준데이터 (공공데이터포털 15012891). 시설 14,635곳의 위치를 씁니다.
- 금천구청 주정차위반 단속기준 공지 (2026-04-28 수정). AI가 공지 문장을 규칙으로 바꾸고 사람이 원문과 대조했습니다(`rules.js`).
- 도로교통법 제2조·제32조, 어린이·노인 및 장애인 보호구역의 지정 및 관리에 관한 규칙 제3조.
- 지도: OpenStreetMap.

## 시연

- `?demo=0` 독산로 지정 금지구간, `?demo=1` 초등학교 옆 길, `?demo=2` 금지구간 밖 주택가
- 화면 아래 시연 도구에서 시각과 요일 종류를 바꿀 수 있습니다.

판정은 안내이며 법적 보증이 아닙니다. 현장의 표지와 노면 표시가 우선합니다.
